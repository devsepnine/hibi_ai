# GitHub 이슈 작성 참고 자료

## 저장소 템플릿

- 대상 저장소의 기본 브랜치에 있는 `.github/ISSUE_TEMPLATE/` 등을 살펴보거나 저장소의 이슈 양식 선택 화면을 사용한다. 로컬 파일은 같은 저장소의 기본 브랜치를 반영할 때 사용한다. fork나 기능 브랜치에는 다른 템플릿이 있을 수 있다.
- `.github/ISSUE_TEMPLATE/config.yml`은 양식 선택 화면의 설정으로 다룬다. Markdown 템플릿의 섹션과 해당 메타데이터는 유지한다. YAML 이슈 양식의 항목별 답변을 준비하고, 저장소에서 해당 양식을 요구하면 그대로 사용한다.
- 요청에 맞는 템플릿을 고른다. 선택에 따라 이슈를 올릴 곳이나 필수 정보가 달라질 때만 사용자에게 묻는다. 대상 저장소에 있는 라벨을 사용하고 미리보기에 표시한다.

## 기본 항목

관찰한 문제나 원하는 결과가 드러나는 제목을 쓴다. 사용자가 요청한 언어를 사용한다. 요청이 없으면 확인 가능한 대상 저장소의 언어 관례를 따른다.

| 유형 | 해당할 때 포함할 내용 |
|---|---|
| 버그 | 실제 동작, 기대 동작, 재현 절차나 발생 조건, 영향을 받는 버전이나 환경 |
| 기능 요청 | 현재의 제약, 원하는 결과, 영향을 받는 작업 흐름 |
| 질문 | 질문 내용, 질문하게 된 배경, 이미 확인한 내용 |
| 작업 | 요청한 작업, 범위, 완료를 판단할 기준 |

문제를 식별하는 데 도움이 되면 에러 메시지를 짧게 발췌한다. 가린 부분을 제외한 원래 표현을 유지한다. 값을 지운 자리는 `[redacted]`처럼 표시한다.
