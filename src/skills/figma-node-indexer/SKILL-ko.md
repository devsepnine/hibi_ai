# Figma 노드 인덱스

선택한 Figma Design 프레임이나 레이어에서 노드 목록을 만들고 원본은 읽기 전용으로 다룬다.

1. 사용자가 준 노드 링크나 커넥터에서 접근할 수 있는 선택 항목으로 시작 노드를 확인한다. 파일 링크만 있고 대상이 불분명하면 시작 프레임이나 레이어를 묻는다.
2. `get_metadata`나 이름과 ID를 반환하는 읽기 도구로 시작 노드와 바로 아래 자식을 읽는다. 이름을 검색하거나 더 깊은 목록이 필요하면 선택한 노드 안에서 관련 자식을 펼쳐 확인한다. 사용하는 도구의 지침을 따른다.
3. 원본 레이어 이름, 정확한 노드 ID, 계층을 유지한다. 도구가 노드 타입을 반환하면 포함한다. 화면에 표시되는 문구는 직접 확인했을 때만 보조 이름으로 적는다. 도구가 메인 컴포넌트 ID를 반환하면 인스턴스 자체의 ID와 구분한다.
4. 도구나 사용자가 제공한 링크를 우선 쓴다. `12:34` 같은 단순 숫자 ID는 같은 Figma 파일이나 브랜치 URL의 쿼리를 `node-id=12-34`로 설정해 링크를 만들 수 있다. 이렇게 만든 링크는 직접 구성했다고 표시한다. 복합 ID이거나 파일이나 브랜치 URL이 확실하지 않으면 정확한 ID만 적는다.
5. 시작 노드의 이름과 ID, 탐색 깊이, 발견한 이름·ID·링크를 목록이나 표로 전달한다. 응답 잘림, 접근할 수 없는 자식 노드, 사용 가능한 읽기 도구가 없는 경우를 명시한다. 명시한 범위의 모든 노드를 읽었을 때만 전체 개수를 적는다.
