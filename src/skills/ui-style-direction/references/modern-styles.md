# Contemporary systems and modernization

Inspect the host platform, installed component library, themes and existing screens first. Preserve the product's visual identity unless the brief asks for a change. The archived Material and Aqua guides describe earlier releases. For a release-specific claim, check the current official source and the version available to the product.

## Choose the system for the surface

- **Fluent 2 for a productivity workspace.** Start with neutral surfaces and existing aliases for text, brand, status and interaction. A library row can use a neutral background, an explicit selection indicator, an independent focus ring and a status label. Reserve elevation for a layer with a reason to float, such as an open command menu. Verify the menu edge and focus in both themes. [Fluent design tokens](https://fluent2.microsoft.design/design-tokens) · [Fluent elevation](https://fluent2.microsoft.design/elevation)
- **Material 3 for a Material product.** Pick the component and then its color role pair. Text on a primary container takes the corresponding on-primary-container role. Keep surface and content roles paired when changing a palette or switching themes. Show the same component on the intended background with selection, keyboard focus and error present where those states can coexist. [Material 3 color roles](https://m3.material.io/styles/color/the-color-system/)
- **Current Apple platforms.** Use the system's available navigation and controls. Where Liquid Glass is supported, it gives navigation and controls a layer above the content. Keep reading surfaces legible over both bright and dark content. Exercise the system's reduced transparency setting and the product's supported older appearance. [Apple materials](https://developer.apple.com/design/human-interface-guidelines/materials)
- **Custom product on the web.** Build from the product's strongest recognizable feature. A catalog for browsing photographs may earn large images and quiet controls. A dispatch console needs aligned values, compact rows and persistent action scope. Specify which content deserves space before choosing corner radii or shadows. The 2018 Material studies Rally and Crane illustrate the difference.

## Change a familiar screen

Identify one task an existing user already knows, such as selecting several invoices and exporting them. Record the command label, how selection is represented, and what remains selected after export. Move those facts into the new component model. A toolbar may become a contextual action bar if the selected count and target remain apparent when focus enters it.

Use a before and after walkthrough with the same data. Try a mixed selection, a long label, and the user's existing keyboard path when applicable. Compare the result and return position. When a workflow intentionally changes, identify the new path in the delivered design.
