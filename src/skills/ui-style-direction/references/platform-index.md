# Archive platform index

Look up a named platform or edition. Each entry identifies an archive folder, a source to locate by title or topic, and one design decision to investigate. Some folders span multiple releases or devices. Choose the edition and input model in the brief.

- **Android**. *Material Design, 2018, Rally and Crane*. Use row density for financial comparison and image hierarchy for destination browsing. Pick the study that matches the user task.
- **Apple historic**. *Macintosh Human Interface Guidelines, 1992, Windows*. Study active window chrome, default commands and selection in monochrome.
- **Apple Mac**. *Aqua Human Interface Guidelines, 2001, Sheets*. Attach a decision to its document. For selection tracking inspectors, use the 2014 OS X guide.
- **Apple iPhone**. *iOS Human Interface Guidelines, 2014, Interactivity and Feedback*. Keep hierarchy and a visible return path as navigation condenses onto a phone.
- **Apple Newton**. *Newton 2.0 User Interface Guidelines, 1996, recognition*. Let the user correct recognized ink before a command acts on it.
- **BeOS**. *BeOS User Interface Guidelines, 1999, Window Creation*. Choose the scope of a floating or modal window from which other work may continue.
- **BlackBerry**. *BlackBerry Smartphones UI Guidelines, 7.1, trackpad devices*. Separate movement through items from committing an action with the trackpad.
- **Commodore Amiga**. *Amiga User Interface Style Guide, 1991, Ghosting*. Give unavailable gadgets a distinct appearance. Test enabled, selected and unavailable states side by side.
- **GEM and TOS**. *GEM User Interface Guidelines, popup menus*. Study how a dialog exposes a choice through a popup. The archive also includes implementation reference entries.
- **GNOME**. *GNOME Human Interface Guidelines, Utility Windows*. Decide whether a preference takes effect immediately or requires Apply. Label dismissal consistently with that choice.
- **Google VR AR**. *Designing for Google Cardboard, 2016, Physiological Considerations*. Keep scene movement under user control and supply stable visual references. For a glance display, use the separate Glass card patterns.
- **IBM**. *Object-Oriented Interface Design, 1993, Object-Action Continuum*. For bulk commands, make object selection and action scope visible before the command runs.
- **Java**. *Java Look and Feel Design Guidelines Advanced Topics, 2001, Wizards*. Use staged pages for a dependent sequence. Keep revisitable steps and their current values identifiable.
- **KDE**. *KDE Human Interface Guidelines, 2021, Master Detail*. Choose simultaneous panes when the user compares items and both panes fit.
- **Kinect**. *Kinect Human Interface Guidelines, 2.0, Engagement*. Show which participant currently controls the cursor before interpreting a gesture as a command.
- **Magic Cap**. *Magic Cap Concepts, Viewables and Stamps*. For a metaphor built around objects, teach which pictured objects can act and what applying one changes.
- **Miscellany**. *Firefox OS Guidelines, 2014, Headers and Lists*. Inspect header, toolbar and list roles together. The IBM guide filed in this folder is a separate system.
- **NeXT**. *OpenStep User Interface Guidelines, 1996, Inspector Panels*. Let one inspector follow selection while keeping the affected document apparent.
- **Nokia**. *Series 40 Touch and Type UI Style Guide, 2010, UI Components*. Choose the keypad, touch, or hybrid model for the specified phone. Keep the meaning of soft keys visible.
- **OPEN LOOK**. *Open Look Graphical User Interface Functional Specification, 1989, Pushpin*. A pinnable command window supports repeated use. Show whether it will stay open after an action.
- **OSF Motif and CDE**. *OSF Motif Style Guide, 1993, shadows and controls*. Use consistent raised and recessed edges for control state and a distinct keyboard location cue.
- **Palm OS**. *Palm OS User Interface Guidelines, 2003, phone lookup*. Offer familiar stored values while allowing direct entry of a known value on a small device.
- **PenPoint**. *PenPoint UI Design Guidelines, 1991, Dual Command Path*. Let a pen gesture accelerate a named operation that users can also reach through controls.
- **RISC OS**. *RISC OS Style Guide, v4, 2024, menus and selections*. Where Adjust keeps a menu open, preserve that repeating workflow in a faithful recreation. Check the target mouse mapping.
- **Samsung**. *One UI Design Guidelines, 2018, Viewing area and Interaction area*. Use reach to place frequent phone controls. The Gear bezel and TV remote guides address different inputs.
- **SGI**. *IRIX Interactive Desktop User Interface Guidelines, Drop Pockets*. A dropped file can populate a path field. Provide a way to confirm or edit the resulting target.
- **Sony Ericsson**. *Sony Ericsson UI Rulebook, 2009, Using soft keys*. For feature phones, show the current action beside the corresponding physical soft key.
- **Surface**. *Microsoft Surface 2.0 Design and Interaction Guide, 2011, Orientation and Layout*. For a shared tabletop, define who owns each manipulation and from which edges labels can be read.
- **Taligent CommonPoint**. *Human Interface Guidelines, 1995, Appliances*. An object can perform an operation on data dropped onto it. Make accepted input and the resulting action visible.
- **webOS**. *HP Touchpad webOS Design Guidelines, 2011, Cards and Stacks*. Open a related activity in another card when users need to switch between both tasks. Group related cards.
- **Windows**. *The Windows Interface Guidelines for Software Design, 1995, property sheets*. Separate an object's editable properties from the command that commits staged changes. Check the edition for XP or later styling.
- **Windows Mobile**. *UI Design and Interaction Guide for Windows Phone 7, 2010, Metro*. Use typographic navigation for related views and preserve a discoverable route beyond a swipe.
- **Windows Office**. *2007 Microsoft Office System User Interface Design Guidelines, contextual tabs*. Reveal object-specific commands when the corresponding object is selected and preserve access to general commands.
- **X User Interface**. *XUI Style Guide, 1988, Default Push Buttons*. Identify the default action before activation and consider whether its effect can be reversed.
