# 아카이브 플랫폼 색인

이름과 판본으로 찾아볼 때 쓰는 색인이다. 자료가 속한 폴더와 원문 제목, 현재 작업에 적용할 수 있는 판단을 함께 적었다. 하나의 폴더에 여러 시대나 기기가 들어 있으면 요청한 버전과 입력 방식에 맞는 원문을 고른다.

- **Android**. *Material Design, 2018, Rally and Crane*. 금융 데이터를 비교할 때는 행 밀도, 여행지를 둘러볼 때는 이미지 위계를 참고한다. 작업에 맞는 사례를 고른다.
- **Apple historic**. *Macintosh Human Interface Guidelines, 1992, Windows*. 활성 창 테두리, 기본 명령, 단색 화면의 선택 표시를 참고한다.
- **Apple Mac**. *Aqua Human Interface Guidelines, 2001, Sheets*. 문서에 속한 결정은 해당 창에 붙인다. 선택을 따라가는 속성 패널은 2014년 OS X 판본을 참고한다.
- **Apple iPhone**. *iOS Human Interface Guidelines, 2014, Interactivity and Feedback*. 휴대폰 폭으로 탐색 구조를 줄여도 현재 위치와 돌아갈 경로를 보여 준다.
- **Apple Newton**. *Newton 2.0 User Interface Guidelines, 1996, recognition*. 인식한 필기값으로 명령을 실행하기 전에 값을 고칠 수 있게 한다.
- **BeOS**. *BeOS User Interface Guidelines, 1999, Window Creation*. 다른 작업을 어디까지 계속할 수 있어야 하는지에 따라 부동 창과 모달 창의 범위를 정한다.
- **BlackBerry**. *BlackBerry Smartphones UI Guidelines, 7.1, trackpad devices*. 트랙패드로 항목을 옮겨 다니는 동작과 명령 실행을 구분한다.
- **Commodore Amiga**. *Amiga User Interface Style Guide, 1991, Ghosting*. 비활성 컨트롤은 구분되게 표시한다. 사용 가능, 선택, 사용 불가 상태를 나란히 비교한다.
- **GEM and TOS**. *GEM User Interface Guidelines, popup menus*. 대화상자가 팝업으로 선택지를 드러내는 방식을 참고한다. 이 계열에는 구현 API 자료도 들어 있다.
- **GNOME**. *GNOME Human Interface Guidelines, Utility Windows*. 설정이 즉시 적용되는지 적용 버튼이 필요한지 정하고 창을 닫는 명령의 이름도 그 결정에 맞춘다.
- **Google VR AR**. *Designing for Google Cardboard, 2016, Physiological Considerations*. 장면 이동을 사용자가 통제하게 하고 고정된 기준점을 제공한다. 짧게 보는 디스플레이는 별도 Glass 카드 사례를 참고한다.
- **IBM**. *Object-Oriented Interface Design, 1993, Object-Action Continuum*. 일괄 명령을 실행하기 전에 선택한 대상과 명령 범위를 드러낸다.
- **Java**. *Java Look and Feel Design Guidelines Advanced Topics, 2001, Wizards*. 앞선 선택에 따라 다음 단계가 달라지는 작업은 단계별로 구성한다. 이전 단계와 입력값을 찾을 수 있게 한다.
- **KDE**. *KDE Human Interface Guidelines, 2021, Master Detail*. 항목 비교가 중요하고 두 영역이 들어가면 목록과 상세를 함께 보여 준다.
- **Kinect**. *Kinect Human Interface Guidelines, 2.0, Engagement*. 제스처를 명령으로 처리하기 전에 어느 참여자가 커서를 제어하는지 보여 준다.
- **Magic Cap**. *Magic Cap Concepts, Viewables and Stamps*. 사물에 빗댄 화면에서는 조작할 수 있는 사물과 그 사물을 적용하면 바뀌는 대상을 알려 준다.
- **Miscellany**. *Firefox OS Guidelines, 2014, Headers and Lists*. 머리글, 도구 모음, 목록의 역할을 함께 본다. 같은 폴더의 IBM 문서는 별도 시스템으로 다룬다.
- **NeXT**. *OpenStep User Interface Guidelines, 1996, Inspector Panels*. 하나의 속성 패널이 선택을 따라가면서 변경 대상 문서를 알려 주게 한다.
- **Nokia**. *Series 40 Touch and Type UI Style Guide, 2010, UI Components*. 지정된 기종에 맞춰 키패드, 터치, 혼합 입력을 선택한다. 소프트 키가 실행할 기능을 화면에 표시한다.
- **OPEN LOOK**. *Open Look Graphical User Interface Functional Specification, 1989, Pushpin*. 고정 가능한 명령 창은 반복 작업에 적합하다. 실행 뒤에도 열려 있을지를 보여 준다.
- **OSF Motif and CDE**. *OSF Motif Style Guide, 1993, shadows and controls*. 일관된 돌출·함몰 테두리로 컨트롤 상태를 표현하고 키보드 위치에는 별도 표시를 쓴다.
- **Palm OS**. *Palm OS User Interface Guidelines, 2003, phone lookup*. 작은 화면에서는 저장된 값 선택과 이미 아는 값의 직접 입력을 모두 고려한다.
- **PenPoint**. *PenPoint UI Design Guidelines, 1991, Dual Command Path*. 컨트롤로 찾을 수 있는 명령에 펜 제스처를 단축 동작으로 연결한다.
- **RISC OS**. *RISC OS Style Guide, v4, 2024, menus and selections*. Adjust로 메뉴를 연 채 반복 선택하는 작업은 해당 판본을 복원할 때 살린다. 대상 마우스의 버튼 매핑을 확인한다.
- **Samsung**. *One UI Design Guidelines, 2018, Viewing area and Interaction area*. 폰에서 자주 쓰는 기능은 손이 닿는 위치를 고려한다. Gear 베젤과 TV 리모컨은 각각의 입력 가이드를 사용한다.
- **SGI**. *IRIX Interactive Desktop User Interface Guidelines, Drop Pockets*. 파일을 끌어 놓아 경로 필드를 채울 수 있다. 결정된 경로를 확인하거나 고칠 방법을 둔다.
- **Sony Ericsson**. *Sony Ericsson UI Rulebook, 2009, Using soft keys*. 피처폰에서는 현재 명령을 그 명령에 대응하는 물리 소프트 키 가까이에 표시한다.
- **Surface**. *Microsoft Surface 2.0 Design and Interaction Guide, 2011, Orientation and Layout*. 공용 테이블 화면에서는 조작 대상의 소유 범위와 어느 쪽에 선 사람이 레이블을 읽는지 정한다.
- **Taligent CommonPoint**. *Human Interface Guidelines, 1995, Appliances*. 객체에 데이터를 놓으면 해당 데이터에 명령을 실행할 수 있다. 받을 수 있는 입력과 실행 결과를 드러낸다.
- **webOS**. *HP Touchpad webOS Design Guidelines, 2011, Cards and Stacks*. 두 작업을 번갈아 해야 한다면 관련 활동을 다른 카드에서 열고 같은 작업의 카드를 묶는다.
- **Windows**. *The Windows Interface Guidelines for Software Design, 1995, property sheets*. 객체의 편집 속성과 변경값을 반영하는 명령을 구분한다. XP 이후의 시각 스타일은 해당 판본을 확인한다.
- **Windows Mobile**. *UI Design and Interaction Guide for Windows Phone 7, 2010, Metro*. 관련 보기 사이를 글자 중심으로 탐색하게 하되 스와이프 이외의 경로도 찾을 수 있게 한다.
- **Windows Office**. *2007 Microsoft Office System User Interface Design Guidelines, contextual tabs*. 해당 객체를 선택했을 때 전용 명령을 보여 주고 공통 명령에도 접근할 수 있게 한다.
- **X User Interface**. *XUI Style Guide, 1988, Default Push Buttons*. 기본 동작을 실행 전에 식별할 수 있게 하고 그 효과를 되돌릴 수 있는지 확인한다.
