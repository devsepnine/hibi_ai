# 데스크톱 편집과 명령 범위

**선택과 포커스.** 포커스가 도구 모음이나 속성 패널로 이동해도 어떤 객체에 명령이 적용되는지 보여 준다. 버튼에 대상 개수를 표시하면 범위를 분명히 할 수 있다. 선택 행, 현재 페이지, 필터 결과 전체가 다르면 어느 집합이 대상인지 명시한다. 트리에서 폴더를 선택하면 하위 항목까지 포함하는지는 명령별로 정한다.

**즉시 편집과 일괄 적용.** 객체를 바꿔 가며 편집할 때는 선택을 따라가는 속성 패널이 적합하다. 즉시 편집 방식은 사용자가 필드 값을 확정할 때 표시된 대상에 반영한다. 나중에 적용하는 방식은 초안을 원래 선택에 묶고 선택이 바뀌기 전에 미반영 상태를 보여 준다. 제품의 방식에 맞춰 적용, 취소, 패널 닫기의 결과를 정한다.

**서로 다른 값과 편집 가능 범위.** 선택한 사진의 별점이 다르면 값이 섞여 있음을 보여 준다. 패널을 열거나 다른 필드를 고쳐도 각 별점은 유지되어야 한다. 사용자가 새 별점을 지정하면 편집 가능한 객체에 그 속성만 적용한다. 일부 성공을 허용하는 제품은 변경된 객체와 건너뛴 객체를 알려 준다. 전체가 편집 가능해야 한다면 명령을 막는 이유를 알려 준다.

**명령의 위치.** 자주 쓰는 명령은 손이 닿기 쉬운 곳에 두고 이름으로 찾을 수 있는 경로도 유지한다. 특정 선택에 필요한 도구는 그때 보여 줄 수 있다. 대화상자는 작업을 멈춰야 하는 객체나 문서에 연결한다. 다른 문서를 열어 둔 채 한 문서를 편집해 차단 범위를 확인한다.

1993년 *Object-Oriented Interface Design*, 1996년 *OpenStep User Interface Guidelines*의 속성 패널, 1995년 *The Windows Interface Guidelines for Software Design*의 속성 시트, *2007 Microsoft Office System User Interface Design Guidelines*의 상황별 탭을 참고했다. 사진 편집은 이 원칙을 새 작업에 적용한 예시다.
