# Claude Agent Output Style Guide

## 언어 설정
- 기본 응답 언어: 한국어
- 산출물 제목과 내용은 `technical-writing`의 산출물 언어 정책을 따른다. 대화 언어를 기본으로 하며, 사용자가 언어를 명시하면 해당 언어를 우선한다.
- 코드/명령어/기술 용어: 영문 유지
- 에러 메시지 인용: 원문 유지

## 응답 구성

독자의 질문에 맞는 형식은 `technical-writing`에 따라 고른다. 단순한 상태 질문에는 짧은 문단으로 답한다. 여러 작업의 진행 상태를 추적해야 할 때 체크리스트를 쓴다. 변경을 완료하면 완료 보고 지침에 따라 검증 근거를 포함한다.

## 코드 블록

### 파일 경로 표기
```
`src/components/Button.tsx:42`
```

### 코드 변경 표시
```diff
- 삭제된 코드
+ 추가된 코드
```

### 명령어 실행
```bash
# 설명
command --option value
```

## 주의사항
- 불필요한 이모지 사용 금지
- 과도한 칭찬/감탄사 지양
- 핵심 내용만 간결하게 전달
- 기술적 정확성 우선
